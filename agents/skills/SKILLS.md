# Skills Map

> Generated by `scripts/generate-skills-index.js --emit`. Never hand-edit — always regenerate.

## Pipeline flow

```
goal → story/defect/topic
story/defect → framing → research → scope → plan → build → qa → close
topic → topic open/close
```

## Goal skill

### /goal

**Input:** the user's goal, any named story/defect/topic id, and the selected downstream skill file.

**Output:** no independent goal artifact. Delegates to exactly one of `/defect`, `/story`, or `/topic`; if continuing an existing tracked story/defect, delegates to exactly one next approved stage.

**Entry gate:** None

**Contract:** the selected downstream skill's normal stopping point. For new story/defect work, this is the framing approval prompt. For topic work, this is the topic-session open/close result. For continued tracked work, this is one sealed stage and its next-step prompt.

## Pipeline skills

### /story

**Input:** the user's request, optional `--domain`.

**Output:** `user/workbenches/topics/work/robot-dojo/wk_robot_dojo/stories/{story_id}/meta.json`, `stage-hashes.json`, `00-scope.md` with `## Original request`.

**Entry gate:** None

**Contract:** the story id, then auto-invokes /framing which presents a framing sentence and stops for approval.

### /defect

**Input:** the user's bug report, optional trace to a story/AC, optional `--domain`.

**Output:** `user/workbenches/topics/work/robot-dojo/wk_robot_dojo/stories/{defect_id}/meta.json`, `stage-hashes.json`, `00-scope.md` with `## Original report`.

**Entry gate:** None

**Contract:** the defect id, then auto-invokes /framing which presents a framing sentence and stops for approval.

### /framing

**Input:** active story `00-scope.md` and `meta.json`.

**Output:** `## Framing` for stories or `## Defect framing` for defects appended to `00-scope.md`; sealed `framing` stage.

**Entry gate:** None

**Contract:** framed summary and `Next: /research`.

### /research

**Input:** approved `framing` stage, `00-scope.md`.

**Output:** `01-research.md` with `## Internal`, `## External`, and `## Recommendation`; sealed `research` stage.

**Entry gate:** None

**Contract:** GO/NO-GO and `Next: /scope`.

### /scope

**Input:** approved `research` stage, `00-scope.md`, `01-research.md`.

**Output:** `## Acceptance criteria` and `## Out of scope` appended to `00-scope.md`; sealed `scope` stage.

**Entry gate:** None

**Contract:** numbered ACs and `Next: /plan`.

### /plan

**Input:** approved `scope` stage, `00-scope.md`, `01-research.md`.

**Output:** `02-plan.md`; sealed `plan` stage.

**Entry gate:** None

**Contract:** plan summary and `Next: /build`.

### /build

**Input:** approved `plan` stage and `02-plan.md`.

**Output:** implementation changes, `03b-criteria.md`, `03-build.md`; sealed `build` stage.

**Entry gate:** None

**Contract:** build result and `Next: /qa`.

### /qa

**Input:** approved `build` stage, `00-scope.md`, `02-plan.md`, `03-build.md`, `03b-criteria.md`.

**Output:** `04-qa.md`; sealed `qa` stage.

**Entry gate:** None

**Contract:** PASS/FAIL and `Next: /close` on PASS.

### /close

**Input:** approved `qa` stage, `04-qa.md`, `03-build.md`, `00-scope.md`.

**Output:** `05-close.md`; sealed `close` stage; `meta.json.kanban = done` when the merge landed on origin/main, else `close-unmerged`.

**Entry gate:** None

**Contract:** story closed.

## Domain skills

Non-pipeline skills invocable at any time:

- **/topic** — Universal Topic opener. Resolves a topic by name, loads its live substrate (INDEX/SYNTHESIS/LOG/SESSION-STATUS) at open, and writes a 4-section Decision/Why/Citations/Next-session-anchors synthesis to the topic's LOG.md and SESSION-STATUS.md at close. Same last state and next steps as the web Recap. Supersedes /work.
- **/write** — Generate prose in the requested voice channel or register. Reads the owner voice corpus from wk_user/user-voice/ (owner-calibrated, gitignored), then drafts to stdout and auto-runs /check on the result.
- **/format** — Render a SEGS content array into a target document format (Google Docs memo style today). Used by build/distribute skills that produce proposal-style deliverables.
- **/kanban** — Manage the story board. View columns, move stories, add backlog items. Miyagi's planning surface.
- **/asana** — Narrow-scope utility for Asana API operations during an active pipeline session — call-note writes, board cleanup, field application, dependency cleanup, and other ontology-bound moves grounded in asana-conventions.md.
