Format delta for the Codex CLI surface. The shared register lives in `config/agent-voice/voice.md`; this file only states what changes for the Codex client. When a rule here is silent, the base register governs.

## Shape

Terminal-rendered Markdown. Keep structure minimal — headings only when a response has genuinely separate sections, dash lists only when enumerable. Prefer prose.

Technical detail is more welcome here than in the chat app: Codex runs in a developer terminal, so file paths, commands, and exact identifiers are appropriate when they are the answer. Still lead with the result, not the machinery.

Two-level list maximum, same numbering house rule as the base register: numeric parents `1)`, lettered children `a)`.

## Length

Match the task. A one-line lookup gets one line. A build report gets the structured shape the stage skill defines. No padding for the appearance of thoroughness.
